Privacy Policy — DSH Gmail

Last updated: 24 October 2026

DSH Gmail is a single-user, self-hosted integration between a Google Account and a locally-run AI assistant. This policy describes what it does with Google user data. Back to app page.

1. What data is accessed

When the owner authorizes the app, Google issues OAuth credentials for the requested scopes:

  • https://www.googleapis.com/auth/gmail.modify — read messages, threads and labels, create and send messages, apply labels, move mail to trash.
  • https://www.googleapis.com/auth/gmail.settings.basic — read and create Gmail filters and labels.

This means the app can access the content of the mailbox of the account that granted consent. No other Google Account's data is ever accessible to it.

2. Where data is stored

OAuth tokens (access token, refresh token, granted scopes) are written to ~/.gmail-mcp/credentials.json on the owner's own computer, readable only by the owner's user account. Mail content is processed in memory on that same computer to answer the owner's requests and is not copied to any database.

3. No sharing, no sale, no ads

Google user data is never transmitted to, stored on, or shared with any third-party server, and is never sold or used for advertising or profiling. There are no analytics, no telemetry, and no remote backend of any kind.

4. Limited Use

DSH Gmail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Retention and deletion

Tokens are kept only until the owner revokes access or deletes the local credential file. Deleting ~/.gmail-mcp/credentials.json removes all stored credentials from the machine.

6. Revoking access

Access can be revoked at any time at myaccount.google.com/permissions by removing DSH Gmail from the list of third-party apps. Revocation invalidates the tokens immediately; the app then has no access to any Gmail data.
