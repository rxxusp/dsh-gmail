DSH Gmail

A private, single-user bridge between Gmail and a local AI agent.

DSH Gmail is a personal integration: a small MCP (Model Context Protocol) server running on the owner's own computer that connects to the Gmail API so a locally-run AI assistant can read, search, draft, send, label, and filter mail on the owner's behalf.

Who uses it

Exactly one person — the owner of the Google Account that authorizes it. It is not distributed, not offered as a service, and has no other users. OAuth tokens are stored locally in ~/.gmail-mcp/ on the owner's machine.

How it uses Google data

It requests the gmail.modify and gmail.settings.basic scopes, which let it act on mail only for the account that granted consent. Nothing is sent to any third-party server: the assistant runs locally, and requests go straight from the owner's computer to Google's APIs.

Full details are in the privacy policy.
